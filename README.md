# PigeonM

Вёрстка лендинга «Business» по макетам Figma.

| Концепт | Страница | Макет |
|---|---|---|
| Концепт 1 | [flexyforall.github.io/PigeonM/](https://flexyforall.github.io/PigeonM/) | [Figma, Concept 2](https://www.figma.com/design/THAEweWSAqB7TEOtSaxAgO/PigeonM?node-id=112-6940) |
| Концепт 2 | [flexyforall.github.io/PigeonM/concept-2/](https://flexyforall.github.io/PigeonM/concept-2/) | [Figma, Concept 1](https://www.figma.com/design/THAEweWSAqB7TEOtSaxAgO/PigeonM?node-id=99-6939) |

Второй концепт лежит в папке `concept-2/` со своими стилями, скриптом и картинками;
шрифты и экран загрузки общие (`assets/fonts`, `assets/loader`). Карточки сегментов во втором
концепте при наведении становятся тёмными и наклоняются (кадр «Cards hover» в Figma).

Чистые HTML + CSS + немного JS, без сборки. Макет — 1440 px; вёрстка тянется на всю ширину экрана (от 1280 px), на 1440 px совпадает с Figma.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Структура

```
index.html          разметка страницы
css/styles.css      стили и токены (цвета, шрифты, отступы из Figma)
js/main.js          переключение вкладок и слоёв карты покрытия
assets/
  fonts/            Outfit и Inter (woff2, self-hosted)
  images/           растровые изображения (фон hero, иллюстрации, план этажа)
  icons/            SVG-иконки и логотип PigeonM
  logos/            логотипы клиентов
  decor/            декоративные линии, сетка, круги покрытия
  loader/           логотип, паттерн и круги для экрана загрузки
```

## Анимации

- Лоадер: строки проявляются слева направо, проценты идут по реальной загрузке картинок и шрифтов, паттерн крестиков проявляется вместе с прогрессом, снизу расходятся волны сигнала. После «Ready» зелёный блок растягивается на весь экран и уезжает вверх, открывая страницу.

- Заголовок hero: курсор проходит по всему тексту и закрашивает полупрозрачные буквы белым.
- Фон hero имитирует видео: само изображение плавно приближается и смещается — бесшовный цикл.
- Логотипы клиентов — бесконечная бегущая строка (пауза при наведении).
- Второстепенный текст выезжает строками из-под своей нижней линии.
- Точечные иконки собираются из квадратиков в случайном порядке.
- Иллюстрации сегментов выезжают снизу, подложка «the coverage.» растягивается слева направо.
- На плане из точки доступа расходятся волны сигнала (заливка + обводка), во вкладках — кольца вокруг точек, квадратики «API [1]» постоянно мерцают.

Секции ниже первого экрана запускаются при прокрутке. Если в системе включено «уменьшение движения»,
анимации отключаются и страница показывается статично, как в Figma.
